# FOXYYA Lite

繁體中文、市場研究及本機模擬交易平台。主分支：`foxyya-lite-railway-deploy`。

## 已實作

- Binance 公開行情、全市場流動性排行及市場機會前五名。
- 七個規則型分析代理入口：市場偵察、技術分析、新聞分析框架、策略驗證、曝險管理、交易檢討、交易手冊。
- 候選池加入、去重、移除、多週期分析、回測結果回寫及曝險檢查。
- 固定基準的前五名批次研究與最近 20 次本機研究儲存；重開時標明歷史研究。可切換唯讀歷史紀錄，匯出選定紀錄 CSV 或全部紀錄 JSON。
- 15 分鐘至月線歷史回測；只使用完整收盤 K 線，與模擬持倉紀錄分離。
- 本機模擬開倉、平倉及交易績效；行情過期或缺少平倉報價時拒絕成交。
- 手機頁籤、44px 操作按鈕、可換行的研究標籤及底部安全空間。
- 行情重畫保留同頁表單、搜尋條件與研究詳情展開狀態。
- 模擬績效與歷史回測權益曲線；僅畫有效資料，缺口不連線。本機模擬曲線為已實現餘額，不包含未平倉浮動損益。
- 回測、全套研究、研究歷史及 CSV 同時提供起始資金、淨損益金額與期末資金；目前固定以 1,000 USDT 為回測基準。

## 止盈、驗證與回測金額

- 本機衍生訊號以當前報價為進場參考：停損距離 1.2%，第一止盈距離 2%，第二止盈距離 3.5%；多空方向相反。這是固定百分比參考，不是 ATR／支撐壓力推導；未設定分批出場比例或自動成交，也未納入 EMA 回測離場。
- 全套驗證按固定策略分類：趨勢 EMA20/50、4 小時、2 年；動能／突破（含趨勢／動能）EMA10/30、1 小時、1 年。七個技術週期中至少五個偏同方向時採趨勢基準。區間均值回歸未實作，維持研究狀態。
- 回測只以已收盤訊號在下一根開盤進場／換向，期末平倉。起始 1,000 USDT、1 倍名目曝險逐筆再投入、固定來回成本 0.08%；不含資金費率、額外滑價或交易所強平模型。資金歸零停止，不保留虛構的 1% 餘額。
- `linear-v2` 已修正空單報酬為 `(進場價 − 出場價) / 進場價`。舊研究的百分比不會悄悄改寫；未記錄起始資金的舊紀錄不換算金額，須重新驗證。候選池的舊本機回測改標待重新驗證，不沿用原本的就緒狀態。
- 淨損益 = 起始資金 × 淨報酬率；期末資金 = 起始資金 + 淨損益。報酬率是期間累計、非年化，一年與兩年不可直接比較。金額與持倉頁模擬帳本獨立。

## 安全與資料邊界

- **PAPER ONLY / REAL ORDER LOCKED**。不修改或呼叫 Production Execution V2。
- 本機模擬、候選及研究歷史只保存在當前瀏覽器，未實作跨裝置同步。
- 雲端 runtime 若有接入，只能讀取；其持倉不可透過本機模擬控制項修改。
- 1.5% 限制目前是模擬保證金占淨值的代理曝險，並非每筆停損風險。
- 新聞及經濟事件仍是分析框架；股票資料源尚未接入。
- 策略建構器是規格模板；ICT、均值回歸、樣本外驗證及正式策略升格仍待實作。
- 歷史研究查閱與匯出不會改動目前研究、候選池或模擬持倉。匯出保留原始紀錄時間；JSON 明確標記歷史、本機來源與模擬交易邊界。
- 曲線不是逐筆行情估值；雲端唯讀快照未提供權益歷史時，顯示資料不足。

## 執行及驗證

在本專案根目錄執行：

```sh
python3 -m http.server 8765 --bind 127.0.0.1
npm test
npm run build
```

本機網址：`http://127.0.0.1:8765/`。測試包括模組、資料邊界、回測、中文顯示、模擬流程與 staging 伺服器檢查。

部署輸出 `dist/` 僅包含公開前端檔案，以及可核對來源提交的 `version.json`。Netlify 使用 `npm run build`，發佈 `dist/`。GitHub「FOXYYA Lite Deploy Check」會測試並上傳相同內容的 artifact；CI 通過本身不代表 Netlify 已上線。

Netlify 純靜態部署不包含私有 runtime gateway；未接入時僅提供公開行情與本機模擬。
