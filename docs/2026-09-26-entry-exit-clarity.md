# 進退場點位與行情時效修正

## 目的與範圍

讓交易建議直接回答進場門檻、兩段止盈、全部剩餘部位的止損，以及第一止盈後如何處理。修正價格顯示精度與行情有效期，不調整既有三策略參數或成本假設，不宣稱提高勝率。

維持 PAPER_ONLY、REAL_ORDER_LOCK、No Backfill。Production Execution V2、canonical ledger、帳戶 NAV、正式下單與前向成交規則均未修改。

## 行為

- 點位共用自適應格式，避免固定三位／八位小數把低價幣的進場、止盈、止損顯示為同價；原始計算值不變。研究價格並未轉為符合交易所委託精度的訂單。
- 交易建議按進場、第一止盈 50%、第二止盈剩餘 50%、止損全部剩餘部位呈現。各出場點顯示相對進場價的價格變動，與成本後研究損益分開。
- 顯示核對時的合約當根 K 線快照價、取得時間、距進場門檻的方向與百分比；明示非串流報價。
- 結構止盈方案顯示下一根起生效的成本保護止損估算；其他方案保留原止損。前向模擬會依觀測進場價重算，並非保證保本。
- 48 根一小時 K 棒包含進場棒；歷史比較用末棒收盤，前向模擬用到期邊界後第一筆連續觀測價格；中斷不補算。
- 核對期限從一小時行情請求開始計算，最長 60 秒，避免分析耗時延長舊快照有效期。
- 有點位的方案必須附可核對的快照價格、高低區間、當根時間與請求／接收時間。缺漏、矛盾或已碰到門檻／止損時不顯示新進場點位。

## 驗證

新增 5 項回歸測試，覆蓋極低價格與 1 USDT 以上的精度、多空相對價格變動、各策略止損說明、慢分析超時、行情參考價與來源時間異常。既有前向測試只更新有效行情樣本的資料來源欄位，不修改成交或紀錄邏輯。

完整 npm test：119 項 Node 測試，加上既有 smoke、研究管線、真實性、架構與 staging 檢查全部通過。npm run build 通過。

## 尚未證明

這些變更不等於策略盈利能力提升。正式帳本、最新淨值與完整部位仍未核對；交易所價格／數量規格、真實滑價及資金費率未完整納入。瀏覽器的 K 線快照也不等於持續成交覆蓋。
