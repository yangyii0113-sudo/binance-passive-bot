```sh
python -m compileall -q research/tw tools/tw_technical_smoke.py
PYTHONPATH=. python -m pytest tests/test_tw_*.py -q
PYTHONPATH=src:. python -m pytest -q
node --test tests/runtime_bridge.test.cjs tests/runtime_layout.test.cjs tests/runtime_metrics.test.cjs tests/runtime_backtest.test.cjs
python tools/tw_technical_smoke.py --end-date 2026-09-18
```

The smoke fetches public exchange data only. It is a historical acceptance run,
not a trading recommendation, live feed or adjusted-price analysis. UI and
stable stock-workspace read-model integration remain scheduled for P3.6.
