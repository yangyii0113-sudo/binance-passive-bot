# 建議前向追蹤第一版

目的：回答每次建議在提出之後是否觸發、模擬成交、出場及產生何種成本後結果。這是獨立研究觀察器，不是正式帳本或 Production Execution V2。

## 邊界與採用方式

- 延續已授權的「建議 → 觸發 → 模擬成交 → 出場 → 損益」工作。第一版使用現有靜態平台、瀏覽器儲存與公開行情，不新增付費後端。
- 使用者在該裝置開啟追蹤後，只納入此後產生的分析；不匯入舊研究、回測或其他本機模擬交易。每個訊號／策略／版本最多登錄一次。
- 每個方案是獨立固定 1,000 USDT 研究情境、0.25% 風險預算、名目最多 1 倍。不同方案不能合併成帳戶收益或組合風險核准；正式 NAV、部位與 1.5% 組合 Gate 維持未核對及鎖定。
- 先接收即時行情，再核對原分析 Gate。沒有合格方案也保存等待／阻擋結論；不強行造樣本。
- 不放寬原策略。成本沿用單邊費率 0.05%、滑價 0.02%；不含資金費率及排隊／深度模型。顯示「研究淨損益（未含資金費率）」而非帳戶報酬。

## 資料與狀態

公開資料：Binance USD-M `/market/ws/<symbol>@aggTrade`，只讀，不含私人帳戶或下單 API。驗證 symbol、事件類型、聚合編號、交易／接收時間、價格與來源；跳號、倒序、延遲、長時間無行情都中止活躍樣本，不補抓過往成交。

每筆固定保存版本、建議時間、原始點位、訊號時間、行情基準、成本、事件及結案原因。狀態：等待條件、未追蹤、等待觸發、模擬持倉、第一止盈、完成、未觸發到期、取消、資料中斷待覆核。

進場使用登錄之後連續即時行情的越價事件。首次看到已越價、已失效、超過一分鐘核對期限或一根訊號期限，不能追價。進場超過門檻一個基本滑價幅度則取消。依實際觀測價格加不利滑價重新核算獨立研究數量與成本後風報比，不擴大風險。

第一目標平一半、第二目標平剩餘；止損採較不利觀測價。結構止盈的成本保護只從下一個小時生效。持有 48 根一小時棒（含進場棒）後，於連續行情的第一筆觀測成交退出；此逐筆模型與歷史收盤回放不完全相同，須在介面揭露。

## 完整性

以 Web Locks 保證同來源只有一個寫入者，另用儲存版本比對防覆寫。沒有鎖／儲存能力就不啟動。格式錯誤、容量耗盡、寫入失敗都停止，保留原始資料。上限 500 筆，不靜默刪除。

離開頁面、切到背景、斷線或重整使尚未完成的樣本標為待覆核；重新開啟只能唯讀查看及開啟新觀察，不重播舊樣本。完成樣本的事件成本可重新計算；未完成、未觸發、等待條件不能算成勝率分母。

## 顯示與驗證

交易建議提供追蹤狀態及「建議成效」入口；成效頁分開列出有效完成、待觸發、持倉、未觸發／取消及待覆核，不把剩餘樣本隱藏。顯示勝率、每筆均值、每筆 R、獲利因子，以及按幣種／策略的結果，無樣本用 —。

具備完整事件 JSON 匯出及複製，注明僅限本機。測試涵蓋雙向進退場、分批出場、下根保護、逾時、跳號與重複行情、首次已越價、舊資料拒絕、儲存損壞／競爭、恢復不回填、無樣本不顯示盈利。

實作順序：純模型與測試 → 儲存與單寫入協調 → 公開行情觀察器 → 現有分析流程與成效頁 → 整體驗證及發布。測試資料只存在測試，不注入公開頁面的績效。
