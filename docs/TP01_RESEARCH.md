# TP01 趨勢回調研究版 v0.1

此為獨立研究假設，並非既有 TF01/ST04 的完整複製；沒有歷史績效結論。
PAPER_ONLY、REAL_ORDER_LOCK、No Backfill 維持。無訂單端點，無自動開倉，無 Production Execution V2 變更。

## 確定性訊號規則

- BTCUSDT、ETHUSDT；僅 Binance USD-M 合約 K 線，不以現貨替代。
- 分別取得最近 600 根 1h、4h；排除未收盤 K 線。至少 200 根 1h、500 根 4h。
- 檢查時間連續、整點對齊、OHLC 正值與上下界；最後一根須為最近已收盤 K 線。失敗時不產生點位。
- EMA 使用 SMA 起始值；ATR14 使用 Wilder 平滑。
- 多：4h close > EMA50 > EMA200，EMA50 大於三根前的 EMA50。空方反向。
- 最新 1h 多方：low <= EMA20、close > EMA20、close > open。空方：high >= EMA20、close < EMA20、close < open。
- close 與 EMA20 距離不可超過 1 ATR14。
- 多方門檻 = 訊號 K 高點 + 0.1 ATR；止損 = 最近五根最低點 - 0.2 ATR。空方反向。
- R = abs(進場門檻 - 止損)。第一止盈 1R、第二止盈 2R；規劃各出場 50%，止損不移動。
- 計畫僅對下一根 1h 有效；止損先到、跳空越過門檻或逾時取消。
- 本版只計算收盤快照，尚未追蹤下一根內的突破、取消、成交與退出；介面不宣稱已觸發或已成交。
- 價格為研究計算值，未套用交易所 tick size；不供直接送單。

## 點位排版

進場獨立大字卡、第一及第二止盈綠色、止損紅色；全部附 USDT。小螢幕依序單欄排列。
舊版 24h 市場動能卡保留，進場標記報價參考；固定百分比目標不作為 TP01 或 EMA 的回測成果。
過期 TP01 計畫隱藏價位，提示重新分析；缺資料與等待条件不顯示虛構點位。

## S1 結構止盈與比較（2026-09-23，覆蓋上方 v0.1 出場／待辦說明）

- 保留 v0.1 進場條件作為基準。新版在最近 120 根已收盤 1h 尋找左右各兩根確認的嚴格 pivot；多方採 entry 上最近前高，空方採 entry 下最近前低。
- 止盈不穿越最近結構，提前 0.1 ATR。TP1 至多 1R，TP2 至多 2R，各 50%。無結構時保留 1R/2R 上限。這不是保證價格會到達的預測。
- 結構空間不足 1R，或分批目標淨收益／含成本止損損失 < 1 時略過。門檻為預先固定研究假設，沒有經歷史資料尋優。
- 單邊手續費 0.05%、滑價 0.02% 為研究假設，不代表帳戶實際費率。顯示的淨風報比為近似估算，並非統計期望值。
- 新版 TP1 後，剩餘 50% 在下一根 K 生效成本保護停損；多空分別依實際滑價／費率解成本中性價格。不能防止跳空虧損。
- 90 天回測以 UTC 最近完整 4h 邊界結束，預載 600 根 1h/4h。前 70% 與後 30% 各自重設 1,000 USDT；沒有自動調參。另跑新版後段雙倍費率及滑價。
- 回測每幣每組單獨跑，一次最多一筆；每筆風險預算 0.25%，名目本金不超過權益。此研究帳本不與正式或前向帳本混合，也不補入正式歷史。
- 下一根開盤越過進場或止損則取消；同根同時觸及進場和止損，無法判斷先後，保守假設先進場再止損。已持倉同根止盈／止損一律止損優先。獲利跳空只按目標成交，虧損跳空按較差開盤。
- 每筆最多持有 48 小時，資料區段末強制收盤退出。分批費用依實際名目金額逐腿計算；PF 使用正負貨幣損益比，無虧損則空值。
- 回撤僅為已平倉餘額回撤，沒有持倉浮虧。資金費率、tick/lot rounding 尚未納入，故即使較高收益也不得升格 PASS。
- 少於 20 筆後段交易顯示樣本不足；收益未超過原版顯示不升格；較高仍僅稱本次後段較高。所有結果為歷史研究，未來盈利未證實。
- 已完成：出場逐筆模擬、成本假設、貨幣帳本、時間分段、雙倍成本對照、網頁操作。
- 尚待：真實資金費率、交易所精度與持倉 NAV 回撤、更長獨立期間、前向觀察。重複使用同一保留區間不得視作新的獨立樣本外證據。
