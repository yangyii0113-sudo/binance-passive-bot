# 出場方式與淨期望值研究

**歷史探索，非 Forward Paper；所有資料均已看過，不是全新樣本外驗證。**

這份研究使用相同進場候選、風險預算與成本假設；比較三種出場方式。正式系統的觀察價格與小時收盤價不同，因此本研究只重現出場決策規則的小時近似版本，不代表正式平台績效。
`close_partial` 與 `close_2r` 使用相同觀察頻率，才能隔離出場政策；與 `ohlc_2r` 比較時，還混有價格觀察方式與成交假設差異。
分批出場合併為一筆完整交易，R 分母固定為原始價格風險。每組仍為獨立 ETH 研究帳戶。

## 決策：暫不將固定成本上限加入正式交易条件

先前固定 2R OHLC 研究中的成本過濾改善，不能外推至分批／移動停損模型。
最後一段、相同收盤觀察的分批模型，基礎成本下：

| 策略 | 不加成本篩選 | 加 0.15R 成本篩選 | 交易數 |
|---|---:|---:|---:|
| B | +1.1754R | −0.5504R | 20 → 11 |
| C | +0.9655R | +0.3742R | 21 → 13 |
| ABCD | +0.8448R | +0.0660R | 21 → 15 |

第一段加篩選後三者也都降低；第二段則提高，沒有跨時段一致優勢。
這修正了先前成本過濾可優先採用的推論：仍可顯示成本，但固定拒絕門檻不應上線。
最後一段未過濾結果雖然正值，第一段壓力成本下 B/C/ABCD 仍分別為 −0.0861R、−0.0934R、−0.0378R，尚未具备穩健獲利證據。
不同出場會改變持倉占用與後續成交，因此組間交易不是完全配對，不能把差額全部解釋成同一筆交易的出場改善。

後續優先解決價格觀察頻率：使用更細的歷史資料或真正新產生的隔離影子觀察，固定規則再驗證。
不調高槓桿、不為了把回測調正而尋找新成本閾值，也不因單一分段好看而升級 Forward Paper。

```bash
PYTHONPATH=src:. python -m pytest tests -q
node --test
PYTHONPATH=src:. python -m backtest.smc_research.exit_study --input /ABS/input.json --output /tmp/exit-study-new
```

程式版本：`51b976bb4d702404cf17a96ac404d5301c5e0ae4`。2982 筆 arm-trades 完成對帳；不同組的交易會重疊，不是獨立樣本。
每筆的 legs、費用、資金費率、MFE/MAE 與回吐值見同目錄逐組 JSON。原始訊號通過率、拒絕原因與出場原因見 comparison.json。
